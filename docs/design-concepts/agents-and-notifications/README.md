Generated with the built-in ImageGen tool as product-design references. These
are exploratory mockups, not implementation specifications.

> The Spanish text in these mockups is not production copy. The shipped app
> remains entirely in English; these images define layout and hierarchy only.

## Shared prompt direction

- Shippable dark macOS desktop UI, using Meanwaile's near-black surfaces,
  warm-white system typography, green working state, amber attention state, and
  rounded geometry.
- Main-screen concepts show running, waiting, and recently completed agent
  executions, with games still available but no analytics or productivity
  scoring.
- Settings concepts retain the current idle-delay and local-port controls while
  exploring independent game/notification behavior, the four combinations,
  notification detail, and quiet-by-default behavior.
- Spanish interface copy, straight-on isolated windows, no browser or device
  mockup, no glassmorphism, neon, or generic admin-dashboard treatment.
